# mydaigest.github.io

Landing page for **DAIGEST**, a free Claude skill that filters your newsletters into one mail.

- Live: https://mydaigest.github.io
- The skill: https://github.com/mydaigest/daigest

`index.html` is generated from the landing source with `build-site.js` (not in this repo). Edit the source, rebuild and push; GitHub Pages serves `main`.
